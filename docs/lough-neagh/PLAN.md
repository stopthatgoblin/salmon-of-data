# Lough Neagh: research before publication

Started 23 September 2026. Scientific validity is the release condition.

1. Inspect the existing static React/Vinext site and preserve its existing trackers.
2. In parallel, audit primary literature, DAERA observations (actual records, not catalogue publication dates), and Copernicus products/access. Save source URLs, raw snapshots and hashes.
3. Acquire Sentinel catalogue metadata and, where possible, relevant reflectance. Establish whether probe locations, depth, timestamps and quality support valid satellite matchups.
4. Construct reproducible matchups with explicit exclusions. Compare atmospheric corrections and simple published/local models only when data support them. Use complete overpasses as validation groups, temporal holdouts and station holdouts where possible.
5. Independently challenge the methodology and evidence. Make an explicit go/no-go decision for absolute turbidity, relative changes and geographic transfer separately. Missing validation is not proof that retrieval is physically impossible.
6. Only after a positive decision, reconstruct usable archive scenes, implement reproducible offshore sectors, cached spatial products and a website with observation dates, missingness, uncertainty and provenance.
7. Verify important scientific calculations and publication gates; run site checks if presentation code changes. Document blockers and the precise data needed to resolve them.

No public turbidity map, synthetic observations, invented performance statistics or automated publication will be created to fill a validation gap. Access limitations will be distinguished from scientific failure. Research outputs remain local until publication is separately warranted.
